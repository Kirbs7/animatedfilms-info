Privacy policy

Last updated: November 9, 2026

This policy describes the owner-operated AnimatedFilms production, YouTube publishing and analytics workflow for the Dr. Crumb channel, formerly Wonder Unpacked Studio. Contact: nimandmallow.studio@gmail.com.

Information we access

AnimatedFilms uses YouTube API Services. When an authorized operator connects a Google account, the app receives OAuth access and refresh credentials, not the operator's Google password. It reads the connected channel's identity and video details, including video identifiers, titles, descriptions, thumbnails, privacy and processing status, publication times and caption tracks.

The app sends the operator's videos, captions, titles, descriptions and related publishing settings to YouTube when authorized. If the operator separately enables YouTube Analytics access, it can also retrieve available video performance statistics, such as views, watch duration and subscriber changes. Analytics access is optional.

How information is used

Information is used to verify the intended channel, prepare and check uploads, manage captions and video details, schedule approved videos, avoid duplicate jobs, and report results to the operator. Optional analytics are used to evaluate the studio's videos.

Where separately authorized by the operator and permitted under applicable YouTube requirements, bounded summaries of performance data and selected episode frames may be processed through OpenAI Codex to produce editorial suggestions. These suggestions and any custom scores are independently generated interpretations, not metrics supplied or approved by YouTube. OAuth credentials are not provided as model inputs. Derived analysis is not yet active; this disclosure is not a statement that an analyst has already processed private Analytics data.

Google user data is not sold, used for advertising, or used to train general-purpose AI models. The workflow does not send OAuth credentials or retrieved private YouTube account data to its narration or artwork generation providers.

Storage and access

The desktop workflow stores OAuth credentials in local credential files and operational records in local files and a local database on the operator's computer. Operational records can include channel/video identifiers, episode metadata, upload state, caption checks, timestamps and optional analytics results.

Access depends on the computer's account and filesystem permissions. Credential files and the operational database are excluded from the project's Git repository. Selected episode metadata and sanitized verification records can be included in project history; credentials and private upload-session URLs must not be included.

Service providers and public content

Google and YouTube process information sent to their services under the Google Privacy Policy and applicable service policies. Publishing a video or its metadata makes that content available according to its selected YouTube visibility. A private upload is not made public by this website.

Separately, the production workflow can send operator-selected scripts, artwork and media prompts to generation providers such as Higgsfield to create production assets. Those submissions are distinct from the app's Google account access.

This informational website is hosted by GitHub Pages. We have not added analytics, advertising, tracking scripts, forms or cookies to these pages. GitHub may process visitor connection information to operate its hosting service; see the GitHub Privacy Statement.

Retention, deletion and revoking access

OAuth credentials are retained only while needed for the operator's authorized connection. Creator-owned scripts, source artwork, locally produced video masters and the studio's own production-cost records are distinct from data retrieved from YouTube. Those original production materials may be retained for the studio's production history until the owner requests their removal; this does not exempt copies of YouTube API data from the rules below.

Stored YouTube API data, including retrieved channel/video details, downloaded caption copies and saved API observations, must be refreshed from YouTube or deleted within 30 calendar days of retrieval or the last verified refresh. An old observation must not be relabelled as a new refresh. Optional authorized Analytics/statistics retained for longer require a fresh authorization and resource-existence check at least every 30 days. The separately authorized read-only Analytics connection was enabled on November 9, 2026. Custom derived analysis remains held pending applicable YouTube requirements and the operator's controls. This policy update does not extend data retention or authorize a new use of data by itself.

Retention review and deletion are handled by the studio operator. The current desktop workflow does not automatically purge files, Git history or backups, or automatically detect every Google revocation. API-data copies in reports, audit captures, project history and backups are included in the operator's review and deletion process; they are not an indefinite-retention exception. Historical records are labelled with their original observation dates. A retained screenshot or old successful response is not proof of current account access.

You can revoke the app's access through Google Account connections. Revocation prevents further authorized API access; it does not itself delete local records, remove uploaded videos, or cancel a publication already scheduled on YouTube. The operator should stop the local worker and manage existing schedules in YouTube Studio when disconnecting.

To request deletion of locally stored account-related records, or ask questions or make a complaint about privacy, email nimandmallow.studio@gmail.com. Identify the affected channel and the data you want removed; do not send passwords, tokens or verification codes. The operator will delete the associated stored user data as soon as possible and within 7 calendar days of a deletion request. Following revocation without a separate deletion request, associated stored API data must be removed as soon as possible and within 30 calendar days. This is an operator-managed process, not a claim that a deletion or revocation has already been tested.

Deleting data held by AnimatedFilms does not delete data held by YouTube. Manage uploaded videos, captions, account data and existing publication schedules directly in YouTube or through an appropriately authorized tool. Removing local credentials alone does not cancel a schedule already saved on YouTube.

Google API data commitment

AnimatedFilms' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Changes

We will update this page when the workflow's data practices change and revise the date above.
